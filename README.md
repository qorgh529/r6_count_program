# R6 팀 점수 계산기

레인보우 식스 시즈 전적에 항목별 점수를 부여해 팀원끼리 점수를 계산·비교하는 웹 앱입니다.
빌드나 서버 없이 `index.html`을 브라우저로 열면 바로 동작합니다.

## 기본 점수표 (화면에서 수정 가능)

| 항목 | 기본 점수 |
|---|---|
| 킬 | 5 |
| 어시스트 | 3 |
| 폭탄 설치 | 2 |
| 폭탄 해제 | 2 |
| 헤드샷 / 데스 / 승리 | 0 (원하면 보너스·감점 설정) |

## 사용법

1. **점수표**에서 항목별 점수를 조정합니다. 데스 감점은 음수로 입력하세요.
2. **경기 추가**에서 선수별 전적을 입력하고 저장합니다. 엑셀/구글시트/CSV를 붙여넣어 한 번에 입력할 수도 있습니다.
3. **순위**에서 여러 경기를 합산한 누적 점수를 확인합니다.
4. 데이터는 브라우저(localStorage)에 저장되며 JSON으로 내보내기/불러오기가 가능합니다.

## 전적 데이터에 대해

R6 Siege는 공식 공개 전적 API가 없어서(Ubisoft 비공식 API 또는 tracker.gg 등 제3자 API는 키·약관 이슈가 있음) 현재는 직접 입력/CSV 붙여넣기 방식입니다.
외부 API 연동을 붙이려면 응답을 `parseStats`와 같은 형태(`{name, kills, deaths, assists, plants, defuses, headshots, wins}`)로 변환해 `state.matches`에 넣으면 됩니다.

## 구조

- `score.js` — 점수 계산·집계·CSV 파싱 (브라우저/Node 공용)
- `app.js` — 화면 로직
- `index.html`, `style.css`
- `score.test.js` — `node score.test.js`로 계산 로직 테스트
